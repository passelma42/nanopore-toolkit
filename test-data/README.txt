The original data file consists of reads for 27 accessions collected from the area around Campus Sterra at UGhent.
All the QC examples discribed in the tutorial (See my repo https://passelma42.github.io/Field-Sequencing/) are taken from this data set.
If you want to test the workflow I have provided a toy data set with reads for 3 accessions.
You can manually download the toy-data here:

wget
 https://github.com/passelma42/Field-Sequencing/raw/main/toy-data.tar.gz
